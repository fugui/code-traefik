## 1. 脚手架模板代码清理与双入口重构策略

现有 `code-template` 生成的示例业务代码在阶段四直接删除重写，**不做任何向后兼容保留**：
1. **彻底移除模板占位资产**：
   - 后端：删除 `handlers/item.go`、`handlers/item_test.go`；从 `models/item.go` 移除 `TemplateItem`（`traefik_items` 表）及示例种子数据，重构为 `models/setting.go`（保留 `TraefikSetting` 对应 `traefik_settings` 治理参数表）。
   - 前端：删除 `frontend/src/pages/DashboardPage.tsx` 与 `frontend/src/pages/ItemListPage.tsx`，替换为五大领域工作台。
2. **保留并升级平台底座组件**：
   - 保留 `handlers/health.go`、`handlers/auth.go`、`handlers/settings.go` 及前端 `AdminSettingsPage.tsx`、`ModuleUserContext.tsx`。
   - 将根目录 `main.go` 迁移重构为同仓双可执行入口：`cmd/server/main.go`（`code-traefik-server`，内嵌 `frontend/dist`）与 `cmd/agent/main.go`（`code-traefik-agent`，零数据库、零 `.pb` 依赖）。

## 4. 全局质量红线与安全验证计划 (Quality Gates & Security Verification Plan)

### 4.1 工程与架构门禁
1. **表名前缀与隔离数据库铁律**：全部 **`30` 张核心业务表**（M1~M20 共 `19` 张；M23 新增 `traefik_proto_doc_symbols`；M24 新增 `traefik_check_rules`、`traefik_vocabulary_terms`、`traefik_check_reports`、`traefik_check_violations`；M25 新增 `traefik_git_repos`、`traefik_git_proto_bundles`、`traefik_proto_files`、`traefik_proto_file_versions`；M26 新增 `traefik_mr_check_runs`、`traefik_notifications`）+ `traefik_settings` 运行配置表（共 **`31` 张 `traefik_*` 模型表**）必须以 `traefik_` 开头；所有数据库单测强制调用 `testdb.SetupIsolatedDB(t)`，严禁将 `TEST_DB_DSN` 指向生产或团队共享库。
2. **主从与命令行隔离防腐门禁**：`go list -deps ./cmd/agent` 输出中严禁出现 `gorm.io`、`code-common/backend/gormdb`、`dynamicpb`、`protoregistry`、`github.com/bufbuild/protocompile`、`github.com/go-git/go-git` 或 `go-billy`（Agent 回传 `ObservedEgressCalls` 仅依赖 `pkg/crosrpc` 二进制头解析）；`go list -deps ./cmd/agent ./cmd/server` 亦严禁引入任何 `sqlite` 驱动，全仓严禁通过 `os/exec` 调用外部 `protoc` 或 `git`。
3. **eBPF 双层测试门禁**：内核探针挂载测试以 `//go:build linux && ebpf` 隔离（无 `CAP_BPF` 时自动 `t.Skip` 并输出原因）；分帧、Mock 匹配、头部自愈与 `/proc` 解析必须在普通非特权环境下 100% 单元测试覆盖。
4. **前端产物体积增量与只读无锁红线**：严禁引入 `monaco-editor` 等 MB 级重型浏览器编辑引擎或在线悲观文件锁字段（`locked`/`locked_by`）；以 M21 交付态构建基线（`__federation_expose_App` ~2.83MB raw / `elk.bundled` ~1.47MB raw）为基准，**`M22~M26` 新增前端静态 JS 构建产物总增量必须严格控制在 `<= 150KB gzip`（`<= 500KB` 未压缩）以内**，所有样式 100% 使用 `--color-*` 语义 Token 兼顾亮暗主题且零 `any`。
5. **后台进程与内核探针卫生**：任何构建、测试或联调结束前，必须确保 `:8091`、`:5181`、`8000`、`8081` 及临时 Mock 端口全部关闭，`bpf_link` 探针 100% 卸载。
